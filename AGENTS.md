# Project Guidelines for AGY / Antigravity

## UI & Design Consistency
- **Preserve Existing UI**: Maintain exact visual layouts, colors, paddings, typography, and widget structures.
- **No Automatic Redesigns**: Do NOT overhaul or change page designs during bug fixes, logic updates, or refactorings unless explicitly requested by the user.
- **Minimal Scoped Changes**: Only change UI code strictly required to fulfill the specific feature or fix.
